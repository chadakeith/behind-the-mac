# Behind the Mac

Mac and Apple notes from Chad Keith.

Live at [behindthemac.com](https://behindthemac.com/) and [chadakeith.github.io/behind-the-mac](https://chadakeith.github.io/behind-the-mac/).

Markdown posts live in [`posts/`](posts/). Home shows the latest 10 as image + excerpt cards; `/blog/` groups the archive by year with the same card layout.

Rebuild `posts/index.json` from markdown with `python3 scripts/build_index.py`.
