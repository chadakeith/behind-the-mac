If you can work comfortably with the Mac’s [four Finder views](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>), y[ou’ll enjoy an ea](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)sier experience when you try to get to your folders and files. Each view has its pros and cons, so using the best view for the job at hand will make you more productive. Here’s a look at the Icon, List, Column, and Gallery views, plus tips on quickly switching views and setting up default views.

You switch between views in the active window by choosing **View**[**> as Icons**, **as Li**](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)**st** , **as Columns** , or **as Gallery**. It’s worth memorizing the keyboard shortcuts for List (Command-2) and Column (Command-3) views so you can switch to them quickly if a particular window isn’t in your preferred view.

### Icon View

Viewing files and folders as thumbnails is the most [visual approach and works be](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)st for people who think spatially—this icon is below that other one. Such people often prefer to arrange icons manually to create memorable groupings, but the Finder can also automatically arrange them in a grid, sorted by different criteria. Icon view works well for:

● **The Desktop:** The desktop can only display its content[s in Icon view, t](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)hough you can open the Desktop folder in a window and use any view in that window.

● **Folders with few items:** When a window shows only a ha[ndful of items, i](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)cons make selection easy. That’s why most software distribution disk images use Icon view to display the app and an icon in the Applications folder.

● **Photos or other images:** Because icons for images can [show a preview of](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>) the image (rather than just the document type thumbnail), Icon view with a relatively large icon size provides a useful visual preview.

![](https://images.squarespace-cdn.com/content/v1/5d67c9fb19efcd000177ca21/23a76d5a-0410-41a1-8813-3c96ed13b8ad/Icon-View.jpg)

To customize Icon view, choose **View > Show View Options**. You [can adjust icon siz](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)e, grid spacing, text size, label position, and background color—or even a background photo. Group By organizes icons into categories, while Sort By keeps them organized by name, date, or other metadata. For folders containing images, increasing the icon size creates a more useful visual preview.

The main limitation of Icon view is that it shows minimal metad[ata—just the file](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)name and, optionally, item info such as image dimensions. It also becomes unwieldy with more than a few files, since scrolling through numerous icons is inefficient.

### List View

When a folder contains more than a few items, List v[iew is usually the most effi](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)cient way to work with it. It displays files in rows with sortable columns showing metadata such as date modified, size, kind, and more. List view is ideal for users who think about files in terms of attributes—when something was created, how large it is, or what type it is—rather than visual appearance. Use it for:

● **Folders containing many items:** Once a folder has more[ items than fit w](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)ithout scrolling, List view makes it easier to view and select items.

● **Sorting folders by date or size:** Whenever you want to[ see the most rec](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)ent files at the top, or quickly identify which consume the most disk space, you can click the Date Modified or Size column header to sort by that criterion.

● **Work with nested folders:** Disclosure triangles let yo[u view the conten](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)ts of multiple nested folders without opening a new window, making it easier to see and move items between them.

![](https://images.squarespace-cdn.com/content/v1/5d67c9fb19efcd000177ca21/b1b51c4e-fcb8-45ae-b1cf-b20dac6042f3/List-View.png)

Customize the visible columns by choosing **View > Show View Op**[**tions** or by Control](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)-clicking any column header. You can add columns for tags, version, comments, and other metadata. Drag column headers to rearrange their order, and drag the dividers between headers to adjust column widths. Sort columns by clicking a column header; click it again to reverse the sort.

### Column View

Column view shows your folder hierarchy as a serie[s of columns, with each column](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>) representing one level of the hierarchy. Selecting a folder reveals its contents in the next column to the right, while selecting a file displays a preview and metadata in the rightmost column. Column view is popular with power users who frequently navigate between folders and appreciate seeing the path to the current location. It’s perfect for:

● **Navigating deep folder structures:** Move through neste[d folders quickly](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>) without opening multiple windows.

● **Understanding file locations:** The column layout shows[ exactly where a ](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)file sits in your folder hierarchy.

● **Quick previews:** Select any file to see a preview with[out opening it or](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>) using Quick Look.

● **Drag-and-drop organization:** Easily drag files between[ folders visible ](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)in different columns.

![](https://images.squarespace-cdn.com/content/v1/5d67c9fb19efcd000177ca21/999f1c15-9fb2-4773-a31a-a980145cecf1/Column-View.png)

One useful option in **View > Show View Options** is “Resize colu[mns to fit filename](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)s,” added in macOS 26.1, which automatically adjusts column widths to accommodate the longest visible filename. Alternatively, you can manually resize all columns at once by Option-double-clicking any column divider. You can also set a default column width and choose whether to show icons and the preview column.

### Gallery View

Gallery view dedicates most of the window to a la[rge preview of the selected fil](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)e, with a row of thumbnails along the bottom and a metadata sidebar on the right. Those who work primarily with images find it useful. It’s designed for:

● **Reviewing photos and videos:** The large preview makes [it easy to evalua](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)te images without opening them.

● **Previewing documents:** PDFs, presentations, and other [documents display](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>) their first page, which can help with identifying similarly named files.

● **Quick Actions:** The sidebar includes Quick Action butt[ons for common ta](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)sks such as rotating images, using markup tools, creating PDFs, and trimming video.

● **Checking metadata:** The sidebar can show detailed info[rmation, includin](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)g EXIF data for photos.

### Setting Default Views

The Finder remembers your view preferenc[es for each folde](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)r indi[vidually, so once](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>) set, they should stick. However, if you’re in Column or List view and open a folder set to appear in Gallery view by selecting it or clicking its disclosure triangle, you’ll stay in the previous view. To open the folder in its assigned view, double-click its icon.

When you create a new Finder window with **File > New Finder Wind**[**ow** , it opens the ](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)folder specified in **Finder > Settings > General**. Set that folder to your preferred view so new windows open as you like.

To ensure a specific folder always opens in a particular view, [select it, choose](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)**View > Show View Options**, and select the Always Open In checkbox. To have its subfolders open in that view too, also select Browse In, if available.

You can also apply view settings to other folders. In View Opti[ons, configure th](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)e settings exactly as you want—icon size, text size, visible columns, and so on—then click Use as Defaults. This makes those settings the default for any folder displayed in that same view type (Icon, List, or Gallery) that doesn’t have its own custom settings. You must set defaults separately for each view type; Column view lacks this option entirely. To revert to system defaults, hold the Option key and the button changes to Restore Defaults.

There’s no need to commit to one view. Switch freely based on w[hat you’re doing—](<https://support.apple.com/en-au/guide/mac-help/mchldaafb302/mac>)List view for finding recent files or cleaning up, Column view for navigating a folder hierarchy, or Gallery or Icon view for reviewing images. The best view is whichever helps you accomplish your current task most efficiently.
