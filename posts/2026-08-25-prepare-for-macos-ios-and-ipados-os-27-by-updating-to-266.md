Apple re[l](<https://support.apple.com/en-us/123074>)eased[ macOS 26.6 Tahoe](<https://support.apple.com/en-us/122868>),[ i](<https://support.apple.com/en-us/123075>)[OS 26.6, a](<https://support.apple.com/en-us/122868>)[nd iPadO](<https://support.apple.com/en-us/123075>)[S 26.6](<https://support.apple.com/en-us/123074>) wi[th a huge n](<https://support.apple.com/en-us/123074>)umber of fixes for security vulnerabilities. However, the release notes for each also include an unusual comment along the lines of “optimizes the Spotlight index in preparation for macOS 27.” At WWDC, Apple promised a rearchitected Spotlight search engine that would be faster and more reliable, so this optimization is likely designed to reduce the time that Spotlight spends rebuilding its index (and thus degrading system performance) after the forthcoming major upgrade. We’ll see how well it works, but for now, consider Spotlight optimization another reason to update to the 26.6 versions using Software Update before you make the jump to the 27 versions later this year.
